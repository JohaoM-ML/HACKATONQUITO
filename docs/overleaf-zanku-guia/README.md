# Overleaf — guía ZANKU (pitch)

Subí **toda esta carpeta** a un proyecto nuevo de Overleaf.

## Cómo subir

1. Overleaf → **New Project** → **Upload Project**  
   **o** New blank → Upload files arrastrando el contenido de esta carpeta.
2. Estructura esperada:

```
overleaf-zanku-guia/
  main.tex
  README.md          (este archivo; Overleaf lo ignora)
  figuras/
    app/
      00-portada.png
      01-login-brigadista.png
      ...
      15-whatsapp-mockup.png
```

3. En el menú izquierdo: **Menu → Main document → `main.tex`**
4. **Compiler → pdfLaTeX** (TeX Live de Overleaf)
5. **Recompile** dos veces (para el índice)
